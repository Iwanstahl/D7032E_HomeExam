# D7032E Home Exam 2026: Exploding Kittens

Home exam in Software Engineering (D7032E) at Luleå University of Technology, by Isak Wanstål (isawan-3).

## The task

Re-engineer a poorly designed version of the card game Exploding Kittens so that it follows the game rules and is easy to extend, modify and test.

## Contents

- `isawan-3/` holds the re-engineered code and the unit tests.
